# Arcade Astronaut

Deep polyphonic synthesizer: analog + wavetable oscillators, three filter characters, cross-modulating LFOs, 8-step sequencer and Skinvoice spectral resynthesis.

This repository only hosts the official installers. The links below always point to the **latest version**.
